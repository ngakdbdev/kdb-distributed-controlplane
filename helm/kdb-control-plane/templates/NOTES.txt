If this is a first install, remember to:
  1. Create the KDB-X license secret (required - pods will crash-loop without it):
       kubectl create secret generic {{ .Values.kdbx.licenseSecretName }} -n {{ .Values.global.namespace }} \
         --from-file=q=./q --from-file=k4.lic=./k4.lic
  2. Set real secrets instead of the chart's dev defaults:
       helm upgrade kdb-control-plane . -n {{ .Values.global.namespace }} \
         --set secrets.jwtSecret=$(openssl rand -hex 32) \
         --set secrets.watchdogSharedSecret=$(openssl rand -hex 32) \
         --set secrets.adminPasswordHash='<bcrypt hash>'
